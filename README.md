## Development Principles

**Practical over ornamental.**  
Software should solve an actual problem.

**Local-first where possible.**  
Keep control and data with the operator.

**Security-conscious by design.**  
Security should be part of the architecture, not an afterthought.

**Observable and understandable.**  
Operators should be able to determine what software is doing and why.

**Documented and reproducible.**  
A project is not complete if nobody can understand, build, verify, or maintain it.
